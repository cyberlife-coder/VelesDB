VelesDB WASM — payloads and metadata filters

Each vector carries a JSON payload. A filter narrows the search to the points whose payload matches, before the top-k cut — so filtering never silently drops results that should have ranked.

What to look for

  • The unfiltered search returns the two nearest vectors regardless of category.
  • The filtered search returns only category = "docs" points, and it can surface a point the unfiltered top-2 had cut.
  • A range filter (gte) and a compound one (and) use the same condition grammar as the REST server.
  • The dimension-mismatch call at the end is supposed to fail — it shows the VELES-004 error shape.
