VelesDB WASM — VelesQL in the browser

WasmDatabase manages named collections and runs VelesQL statements against them: DDL, insert, projected select, vector NEAR search, introspection. Same grammar as the REST server, smaller supported surface.

Contract worth memorising

  • executeQuery(sql, paramsJson) — the second argument is a JSON string (or null), not an object. Parameters are written $name in the statement and supplied under the bare key name.
  • The result exposes kind ("rows", "mutation", "deletion", "ddl", "admin", "train"), rowCount, message and rowsJson — one JSON.parse per query.
  • For mutations, rowsJson is "[]" and rowCount is the affected-row count; no placeholder rows are allocated.
