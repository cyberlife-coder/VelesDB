VelesDB WASM — surviving a reload

An index built in the tab is gone on refresh unless you persist it. save() writes it to IndexedDB, VectorStore.load() reads it back. The same bytes are available synchronously through export_to_bytes() if you would rather store them yourself (a file, an <input type="file">, your own backend).

How to actually test persistence

  1. Load the page: it reports no saved index and builds one.
  2. Press Reload the page: it now loads 4 vectors back from IndexedDB without re-inserting anything.
  3. Press Delete the IndexedDB database, then reload: you are back to step 1.
